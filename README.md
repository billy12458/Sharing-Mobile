# Quicky Sharing Mobile

Mobile frontend for **Quicky Sharing**.

This repository contains the mobile-oriented frontend implementation of the
Quicky Sharing file-sharing platform, including mobile navigation, file
browsing, search, tags, profile management, login/session management, feedback,
file extraction, and other related UI components.
